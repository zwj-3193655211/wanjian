## 指尖万剑 v1.0.0

基于 MediaPipe 手势识别的 3D 飞剑阵型控制应用。通过手指数量切换 6 种剑阵，支持鼠标模式。

### ✨ 功能
- **6 种手指阵型**：0-5 根手指对应混元阵/游龙阵/浑天阵/凤凰阵/莲花阵/万剑落
- **实时手势识别**：MediaPipe Hands 高精度检测，完全离线运行
- **3D 渲染**：React Three Fiber + Three.js，炫酷粒子特效
- **鼠标模式**：未检测到手时自动切换
- **可调参数**：Tab 键打开设置菜单
